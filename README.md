# صفحة توثيق حضور احتفالية يوم المبرمج العراقي (تُحفظ في Excel)

الصفحة تحفظ توثيق كل حاضر ومشارك (مع انطباعه عن الاحتفالية) كصف جديد في جدول Google Sheets، وتنزّله وقتما تشاء كملف Excel.

## 1) إنشاء الجدول والسكربت (5 دقائق)
1. افتح https://sheets.google.com وأنشئ جدولًا جديدًا فارغًا (سمّه مثلًا «مشاركو يوم المبرمج»).
2. من القائمة: **الإضافات (Extensions) ← Apps Script**.
3. امسح الكود الموجود والصق محتوى ملف `Code.gs` ثم احفظ.
4. اضغط **نشر (Deploy) ← نشر جديد (New deployment)**:
   - النوع: **تطبيق ويب (Web app)**
   - تنفيذ باسم: **أنا (Me)**
   - من لديه حق الوصول: **أي شخص (Anyone)**
5. اضغط **نشر** ووافق على الصلاحيات (إن ظهر تحذير: متقدم ← المتابعة).
6. انسخ **رابط تطبيق الويب** (ينتهي بـ `/exec`).

## 2) ربط الصفحة
افتح `index.html` وضع الرابط مكان `PUT-YOUR-APPS-SCRIPT-URL-HERE`.
جرّب الصفحة بفتح الملف في المتصفح وتعبئة بيانات تجريبية، ثم تأكد أنها ظهرت في الجدول (احذف الصف التجريبي بعدها).

## 3) النشر على GitHub Pages
1. أنشئ مستودعًا على GitHub وارفع الملفات (`index.html` وبقية الملفات).
2. **Settings ← Pages ← Source: GitHub Actions**.
3. يظهر الرابط: `https://YOUR-USERNAME.github.io/اسم-المستودع/`

## 4) تنزيل ملف Excel
من Google Sheets: **ملف ← تنزيل ← Microsoft Excel (.xlsx)**. للفرز والتصفية استخدم أدوات Excel أو الجدول مباشرة.

## ملاحظات
- إن عدّلت `Code.gs` لاحقًا فعليك **نشر إصدار جديد** (Deploy ← Manage deployments ← Edit ← New version).
- هذه النسخة بلا حماية متقدمة عمدًا: من يعرف رابط السكربت يستطيع إرسال بيانات إليه، ومن يملك صلاحية الجدول يرى البيانات. لا تشارك الجدول إلا مع المسؤولين.

## أعمدة الجدول
التسلسل، رقم التوثيق، الاسم الرباعي، رقم الهاتف، المحافظة، الدولة، الانتماء للنقابة، الانطباع عن الاحتفالية، تاريخ التوثيق.

## تحديث من نسخة سابقة
إن كنت قد جرّبت النسخة السابقة وظهرت ورقة «المشاركون» بأعمدة قديمة، احذف تلك الورقة (أو غيّر اسمها) ثم الصق `Code.gs` الجديد وانشر إصدارًا جديدًا، فتُنشأ الورقة بالأعمدة الصحيحة تلقائيًا عند أول إرسال.
